# 🚀 YSMParser-Pro (GUI Edition)

这是基于 [OpenYSM/YSMParser](https://github.com/OpenYSM/YSMParser) 的图形化增强分支。

> **告别繁琐的命令行，让 YSM 模型解密触手可及。**

---

## ✨ 核心特性

* **全图形化操作**：专为新手设计，支持点击按钮选择文件夹。
* **深色模式 UI**：基于 GitHub 风格的极客黑皮肤，美观且护眼。
* **智能路径适配**：完美适配 YSM V3 逻辑，自动处理复杂的目录结构。
* **实时解析日志**：在窗口中即时查看每个模型的解析进度。

## 📥 如何使用

1.  **下载工具**：前往 [Releases](https://github.com/Phoebemc-sb/YSMParser-Pro/releases) 下载打包好的 `main.exe`。
2.  **核心文件**：由于版权原因，本项目不包含原版核心。请将 `YSMParser.exe` 放在 `main.exe` 同一文件夹下。
3.  **启动**：双击 `main.exe`，选择包含 `.ysm` 的文件夹即可开始。

## 🛠️ 开发者指南 (源码运行)

如果你想通过 Python 运行：
1. `pip install PySide6`
2. `python main.py`
